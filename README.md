# Equilibrium – Website

Marketing website for Equilibrium, an AI personal finance app I built and launched solo in June 2026 (300+ downloads across 14+ countries).

📱 App Store: https://apps.apple.com/us/app/expense-tracker-equilibrium/id6778774923

📱 Google Play: https://play.google.com/store/apps/details?id=com.arizkhan.equilibrium


## What's here
- Responsive landing page showcasing the app's screens
- Feedback form connected to the app's API
- Privacy page

## Stack
TypeScript, HTML, CSS (update if needed)

## About the app
The mobile app itself is built in React Native with AI voice expense logging, budgeting and PostHog analytics. Its source is private, and I'm happy to walk through it in an interview.
